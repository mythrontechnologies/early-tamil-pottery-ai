# knowledge/periods

**No entries yet, deliberately.** The knowledge base holds only statements the project can tie
to a source it has read or bibliographically confirmed (see `knowledge/references/references.yaml`).
No such source in the project yet supports entries of this kind, and none may be invented.

The project's working chronology (named periods and the competing positions on the earliest
Tamil-Brahmi) lives in `configs/project.yaml` under `chronology:` and is read from there by
`src/dating/chronology.py`. It is not duplicated here.
